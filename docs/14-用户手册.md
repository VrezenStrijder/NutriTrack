# 14 · 用户手册

> 面向使用者。安装、日常怎么用、数字看不懂时怎么查、出问题怎么自救。
> 开发细节不在这里：数据口径看 `docs/02`，在线源看 `docs/05`，备份格式看 `docs/04`，
> Android 的差异看 `docs/11` / `docs/12`。

程序在系统里显示的名字是 **知食（NutriTrack）**，安装包、快捷方式、通知标题都用这个名。

## 一、装在哪儿、怎么启动

| 平台 | 拿到的文件 | 怎么装 |
|---|---|---|
| Windows 10/11 | `NutriTrack-0.3.0-windows10-x64-setup.exe` | 双击安装，默认装到用户目录，带开始菜单快捷方式与卸载项，不需要管理员权限 |
| Windows 7 SP1 / 8.1 | `NutriTrack-0.3.0-windows7-x64-setup.exe` | 同上，但系统要先补齐运行库（见安装时的提示） |
| Android 8.0+（arm64） | `NutriTrack-0.3.0-android-arm64.apk` | 传到手机点开安装；首次会提示「允许安装未知来源应用」 |

安装包里是**单文件**，只有原生库（Skia 等）在旁边的目录里。想换成绿色版：装完后把安装目录整个拷走也能跑；
打包工具也支持生成散装目录，用于逐个文件排障。

两个平台的数据各自存在本机，**互不同步**。换设备或换平台靠备份包搬：
Windows 是「设置 → 备份与导出 → 导出备份」，Android 是同一个入口，导出后系统会让选保存位置。

第一次打开需要几秒（要把 10 MB 的离线成分库解压到应用目录），之后是秒开。**全程不需要联网**，
联网只在三种情况下用到：查在线数据源、拍照识别、导出后分享。

## 二、先建一份档案

打开后如果是空的，先去「我的」建档案。档案决定三件事：**详情页推荐的份量、记录页的目标线、
建议页给你的条目**。家里人各建一份，随时切换，互不干扰。

要填的项：昵称、性别、年龄、身高、体重、活动水平、目标体重（可留空）；再勾「已确诊的病症」
（可多选）、填「食物过敏原」（逗号分隔，如 `花生,虾`）、选「重点关注指标」。
勾了什么，详情页就会把对应指标顶到前面并标色，建议页也按它出条目、调整严格程度。

- 不填病症也能用，只是建议会更「通用」
- 目标体重、腰围可以后面在「体重记录」里补
- 换成家里其他人用：桌面端点侧栏顶部的当前成员，手机端点「我的」→ 切换；不需要重登

## 三、查一个食物的成分

### 3.1 搜索

首页顶部就是搜索框。中文名、拼音全拼、拼音首字母都认：

| 输入 | 结果 |
|---|---|
| `苹果` | 名称含「苹果」的全部条目 |
| `pg` | 拼音首字母命中的条目，苹果排在前面 |
| `西红柿鸡蛋三文治` | 库里的正式名是「番茄蛋三文治」，靠别名指过去 |
| `fq` | 同上，首字母写法 |

结果是**边打边出**的，不用按回车。搜索框下方一行会写清命中多少条、来自哪个库。

### 3.2 首页的「常见食物」

不知道搜什么就点这里：按日常频次排的食物胶囊，点一下直接进详情。这一块完全离线。

### 3.3 在线查询（可选）

搜索结果上方有「在线来源」区，列出三个源：中国营养学会、USDA（美国农业部）、
Open Food Facts。三个源**并行**查，谁先回谁先上屏，不会互相等。

- 默认不需要任何配置就能查（用的是各家的公开查询接口）
- 想更快或想避免限速，可以在「设置 → 在线数据源」里填自己申请的 API Key
- 查到的条目卡片上会标来源；外文条目会带「外文名」标记，数值口径与离线库不一定一致
- 结果在本机缓存 7 天，重复搜同一个词不再联网；点「全部刷新」可以跳过缓存重查
- **在线查不到不影响使用**：离线库有几千条常见食物，核心功能全在本地

## 四、看懂食物详情页

顶部横条上是「返回」「复制摘要」「收藏」。复制摘要按**当前份量**生成一段纯文本，
方便贴到聊天里；收藏点一下即切换，已收藏是实心。

正文自上而下的顺序是固定的：

1. **名称与来源**：下面一行写清这份数据的出处与被测部位（生/熟、可食部百分比）
2. **能量与三大营养素**：大号是这一份的能量，下面三行是蛋白质、脂肪、碳水及其占每日目标的百分比
3. **GI 与 GL**：血糖生成指数与血糖负荷，上下两块同构展示。GI 评价「这种食物升糖快不快」，
   GL 评价「按你实际吃的量，总影响有多大」——低 GI 但吃一大盘，GL 一样会高。
   没收录的条目显示「未收录」，不是 0
4. **嘌呤 / 草酸**：分级（低/中/高），给痛风、肾结石的档案用。**是估算值，不是实测**，
   同类食物之间差异很大，只用来做方向性判断
5. **按份折算**：中间的「− / +」调份量，上面所有数值跟着重算——想换算成自己实际吃的量，
   在这里调比拿计算器快
6. **配料组成**：菜品类条目会列出配料，点某一味直接跳到它的详情页，返回回到原处；
   旁边有复制按钮，一次把配料名全拷走
7. **建议份量与注意事项**：按当前档案给出的「这一餐吃多少合适」，带家用量词（半碗、一个、一把），
   下面逐条列出要注意的地方及依据。换档案会变，这是正常的
8. **加入今日餐次**：选份量 → 选早/午/晚/加餐 → 入账。手机上是自下而上的抽屉，桌面是居中浮层
9. **同名 / 同义条目**：同一件食物的其他叫法，以及同名但可能不是同一种东西的条目——
   买错东西常常栽在这里

没有建档案时第 7、8 两块不出现，其余照常可看。

## 五、分类浏览

「分类」页按 15 个大类列全部条目：谷物薯类、豆类及制品、蔬菜、水果、畜禽肉、水产、蛋类、奶类、
坚果种子、油脂、糕点甜食、饮料、调味品、加工食品、其他。可以「类别 + 关键字」联合过滤。
想系统性地看某一类有什么，用这页比搜索快。

## 六、记录今天吃了什么

「记录」页是主战场，按日期 + 餐次分组（早餐 / 午餐 / 晚餐 / 加餐）。

- **加一条**：在食物详情页点「加入今日餐次」。记录页本身不搜索，只负责组织与编辑
- **改份量**：点条目 → 抽屉里改份量、换餐次、删除。手机上是从下往上拉的抽屉，不是居中弹窗
- **两种能量口径并排**：大号是标示能量，旁边小字是 Atwater 计算值；两者差得超过阈值会单独
  提示「两种能量口径对比」，并说明可能的原因
- **当日卡片**：能量、蛋白质、脂肪、碳水对着档案目标的完成情况；达标、未达标、超标是三种
  不同的显示，不要混着看
- **补记以前的日子**：把日期切到那一天，再回到详情页加入，条目就落在那一餐上
- **分享**：把当天餐次明细导出成图片或 Markdown，发给自己或家人

### 6.1 常用组合

一顿饭总是那几样时，存成「组合」：餐次卡右上角有个入口，把**这一餐**整体存成组合并起个名字，
下次一键全加进来。也可以把这一餐并进已有的组合。同名会覆盖，不会存出两个同名组合。
组合跟着备份包走，换设备不丢。

## 七、看周/月汇总

记录页在 7 天柱图下面有「周 / 月汇总」按钮，点进去看这段时间的能量曲线、三大营养素占比、
餐次分布。柱状图上的每一天都能点开回看当天明细。**缺口会被标出来**（那天没记），
「没记」和「吃了 0」是两回事。

## 八、建议页

建议页自上而下几块，都是按当前档案算的：

- **档案概览**：每日能量目标、基础代谢、已确诊的病症与过敏项——先看这一块，数字不对先改档案
- **长期饮食原则**（默认收起）：来自《中国居民膳食指南（2022）》与你档案里病症对应的饮食原则。
  每条下面的灰字是出处（「准则N」指指南条目，标病名的来自家庭实用版）。点「明细」看为什么、
  怎么做、注意什么，明细里可以左右翻页。这块只看档案，不随今天吃了什么变
- **今天怎么吃**：按当前时段 + 前面几餐已经吃了什么，说清下一餐该补什么，比如「今天蛋白质只到 62%，
  晚餐可加一份豆制品」，下面给几条能直接记的具体食物
- **推荐食谱**：从内置菜谱库里按你档案的病症标签挑几条，卡片上写明「为什么推这条」（比如「低钠」）、
  一份的能量与三大营养素、用了哪些配料。「加入记录」会把配料按克数拆成多条写进下一餐，
  不是记一条「吃了这道菜」——这样每一项食材都还能单独核对。没有匹配的食谱时这一块不出现
- **能量与营养素完成度**：对着今天的记录算；还没记录时显示「今天还没有记录」
- **针对你的建议**：一条条结论（提示 / 推荐 / 注意），右侧复制按钮可以单独复制某一条
- **这些数字是怎么来的**：基础代谢公式、活动系数、各项指标参考值的出处

顶栏四个图标：**导出**（生成 HTML 报告）、**打开**（用浏览器打开最近生成的那份）、
**复制**（报告全文）、**刷新**。折叠状态会被记住，下次进来还是你上次的样子。

没有档案时这一页只显示一句说明——它不猜「成年人平均需求」，因为那对具体的人常常是错的。

## 九、我的：档案、体重、收藏、菜品

| 入口 | 能做什么 |
|---|---|
| 当前档案 | 改资料、看目标与重点指标；「全部档案」里切换或新建 |
| 体重记录 | 每次称重记一条（按当天日期落账，不做「今天覆盖」）；记体重与腰围，按天分组看日/周/月趋势 |
| 收藏 | 常吃的食物与自建菜品，可分类 |
| 我的菜品 | 自己搭的组合餐（比如「我的早餐套餐」），也能收藏 |
| 设置 | 见下一节。手机端在「我的」里，桌面端在侧栏 |

体重页的备注框可以写「起床空腹」「晚饭后」「运动后」——同一天多次称重时，
靠它区分哪条更可信。

## 十、设置

设置是**全局**的，与当前档案无关：换个家庭成员用，主题和 Key 都不用重配。

### 10.1 外观

- **主题**：浅色 / 深色 / 跟随系统
- **主题色**：森林绿（默认）、深海蓝、靛紫、琥珀、玫红、青灰；深色下会自动换成同色系的高明度版本，
  保证按钮与高亮数字的对比度
- **字号**：小 / 标准 / 大，立即生效并保持

### 10.2 记录提醒

两个提醒：**吃饭提醒**（到点今天一条都没记才提醒）与**称重提醒**（到点今天还没称才提醒）。

- Windows：靠程序内的定时判定，所以「关窗口不退出」是提醒能响的前提——关掉窗口只是收进托盘，
  在托盘图标上右键才是真正退出
- Android：走系统闹钟 + 通知。需要在首次提示时允许通知权限；系统回收应用后靠非精确闹钟兜底，
  可能晚几分钟到十几分钟。想要准时，还要在系统设置里允许本应用后台运行、并关闭电池优化
- 通知上有三个动作：「去记录」（称重提醒里是「记体重」）、「10 分钟后」、「知道了」。
  点「10 分钟后」会真的等十分钟再判一次，不是把卡片藏起来
- 拿不准通知到底会不会来：点这一块下面的「发一条测试通知」，立即发一条，看屏幕顶部有没有出现。
  没出现就是被系统或厂商管家拦了，去「去系统设置」里放行

提醒只在**到点时确实没记**才发出，不会连着骚扰。

### 10.3 视觉模型（拍照识别）

拍照识别需要你自己准备一个大模型 Key（兼容 OpenAI 协议的视觉模型，通义千问 VL、GPT-4o 之类）。

1. 「添加配置」→ 点一个服务商预设，地址与模型名自动填好
2. 填 API Key（只存在本机，加密落盘，不上传）
3. 可以先「查模型列表」确认 Key 能用

识别结果永远是**待确认的候选**：份量是你可改的估算值，采纳前请自己核对。没配 Key 时扫描页会
引导你用手动搜索，功能不缺。

### 10.4 在线数据源

三个源的开关、各自的 API Key、以及每个源的「测试」按钮。点了会真的发一次请求，并告诉你
返回多少条、耗时多少——**这是排查联网问题最快的地方**。

失败时会说明原因，常见的几种：

| 提示 | 意思 | 怎么办 |
|---|---|---|
| 设备现在没有网络 | 系统报告无连接 | 开 Wi-Fi/流量；飞行模式关掉 |
| 域名解析失败 | 拿不到 IP，通常是断网或代理 | 检查网络与代理设置 |
| 连接被拒绝 / 连不上 | 请求到了但没人应答 | 公司网络或防火墙拦截，换个网络试 |
| 对方要求 TLS / 证书问题 | HTTPS 握手失败 | 系统时间是否正确；是否被中间人代理 |
| 权限被拒 | Android 包缺联网权限 | 正常情况下不会出现；出现请反馈 |

同一套 Key 在 Windows 能用、手机上「连接失败」，多半是手机网络本身的问题（上面几行会指出是哪种），
不是配置错了。

### 10.5 备份与导出

- **备份包（.zip）**：档案、收藏、用餐记录、常用组合、体重腰围、在线补录、自建菜品、全局设置，
  全在里面。换设备、重装前务必导出一份
- **CSV**：按表导出，给 Excel 用（带 BOM，中文不乱码）
- **建议报告**：导出成 HTML，可以分享、打印
- **自动备份**：每周一份，留最近 4 份，放在应用数据目录
- **API Key 默认勾选导出**：还原到别的机器不用重填；但备份包是明文 zip，勾了就意味 Key 在文件里，
  **不要随手外发**。不想带 Key 就取消勾选，包里完全不含

导入时会先给预览：这个包里有什么、当前库已有什么、哪些是重复的，再让你选冲突策略
（跳过 / 覆盖 / 合并）。导入不会静默覆盖，看清楚再确认。

### 10.6 在线补录条目

在线查到的条目如果补进了自己的库，会集中在这里：显示有多少条，可以「管理」逐条看/删，
也可以一次清空（要连点两次确认）。清空会连同这些条目的收藏一起删掉，**已记的餐不会受影响**
（记录里存的是当时的数值快照）。

### 10.7 本地数据与完整性

这一块把两个库的路径与大小列出来，并且可以「检查完整性」：只读地看库能不能打开、关键表在不在。
库损坏、路径被改、或者「打不开/数据空了」时，先点这里。

- 成分库（只读，随程序分发）：损坏就重装程序
- 用户库：你自己的数据，**先导出备份再动手**

### 10.8 崩溃日志与软件信息

程序崩了会自动把现场写进日志。反馈问题时，「导出诊断包」比描述「点了一下就没了」有用得多。
诊断包里不含你的 Key，也不含用餐记录明细。

软件信息里有版本号、运行环境、数据库 schema 版本、凭据存储方式——反馈时一并贴上。

### 10.9 软件更新

入口在设置页「在线数据源」下面那张「软件更新」卡片：

- **自动检查**：默认开着，启动后几秒内静默查一次，没网不会弹任何提示。关掉开关就不再自动查。
- **手动检查**：点「检查更新」。没事就是「已是最新版本 v0.3.0」，有事会显示新版本号与更新说明。
- **发现新版时**：电脑上会在**屏幕右下角**弹一张提示卡（不是程序窗口里），程序最小化或收到托盘后也照样能看到；手机上贴着主界面显示。
- **Windows**：「下载并更新」会下载安装包、校验哈希，然后**装回你当前程序所在的目录**，装完自动重新打开。不需要你选路径，也不会装出第二份。
- **手机**：下载完会拉起系统安装器，第一次要允许「安装未知应用」；授权后再点一次就会装上。
- **不想自动装**：点「打开发布页」，自己下安装包，装法与平时一样。
- **免安装运行**（解压即用、没走过安装器）：程序识别不到安装信息，按钮会变成「前往下载」，请手动安装。

更新包会在下载后核对 SHA-256，对不上直接丢弃重来，不会拿半截文件去跑安装器。

## 十一、几条通用操作

- **复制**：食物卡片、详情页、搜索结果上都有复制按钮，复制的是可粘贴的纯文本
- **回到最上**：长页面滚一段后右下角出现按钮
- **返回**：Android 返回键逐级回退，一级页面再按一次退回桌面（进程还在，回来还是原样）
- **收藏怎么取消**：再点一次收藏图标即可（已收藏是实心）。收藏页里可以建分类、改名、删分类，
  换一件东西分类在收藏页顶部操作
- **触屏没有悬停**：图标按钮旁边都有可见文字，别找 tooltip

## 十二、常见问题

**搜不到想找的食物**
换更短的关键词（「鸡胸肉」搜不到就试「鸡胸」）；试拼音首字母；看看「分类」页对应大类里有没有。
库里没有的，可以用「在线查询」补，查到后可以「补录」进自己的库。

**在线有结果但数值和离线库不一样**
两个库的测定方法与样品不同（生/熟、部位、品牌），差 10~20% 很常见。离线库优先用于日常记账，
在线数据用于补缺。

**详情页没有「加入今日餐次」**
没有档案时不能记餐。去「我的」建一份档案，回到详情页就会出来。

**数字旁边写着「未收录」**
这项数据没有测定值，不是 0。膳食纤维、GI、嘌呤、草酸都可能缺。缺了就按「不知道」处理，
不要当「没有」。

**建议页说我没吃够，但我记了**
先看那天的记录有没有漏餐次；再看建议是按「已记的部分」算的，没记的它不知道。
把日期切到那一天把漏的补上，建议会跟着变。

**提醒不来**
按这个顺序查：① 设置里对应提醒是否打开；② 通知权限是否允许；③（Windows）窗口是不是被真正退出了；
④（Android）电池优化是否放行、是否允许后台运行。设置页顶部的提示会直接告诉你缺哪一项。

**换手机了，数据怎么搬**
旧机「设置 → 备份与导出 → 导出备份」，把 zip 传过去；新机同一个入口「从备份包恢复」。
Android 上也可以用系统分享把包发过去，或者先把包放「下载」目录再选。

**字体调到最大后有点挤**
应用内字号与系统字号是两套。应用内选「大」是按比例放大；系统字号特别大时个别胶囊会换行变高，
但不会截断文字。真遇到截断请反馈，附截图。

**耗电**
离线使用几乎不耗电。在线查询与拍照识别才有网络活动。Android 的提醒用的是系统闹钟，不是常驻轮询。

## 十三、边界（请务必知道）

- 营养成分是**公开食物成分表的代表值**，同一食物不同产地、部位、做法差异很大
- 嘌呤、草酸是**分级估算**，不能当医嘱
- 营养建议基于膳食参考摄入量推算，**不构成医疗诊断或治疗建议**。有糖尿病、肾病、痛风等
  疾病时，请以医生与营养师的方案为准
- 在线数据来自第三方公开接口，随时可能变更或停用；停了不影响离线功能
- 程序不做账号体系，数据只在本机。备份与保管是你的责任
